# Wyckoff 2.0 专业审查与整合说明

## 审查范围

本次审查对照了：

- 现有在线课程：6 个阶段、24 章、完整的 Wyckoff 结构、执行、研究与治理内容。
- Rubén Villahermosa 的 *Wyckoff 2.0: Structures, Volume Profile and Order Flow*：8 个部分、342 页，重点覆盖高级结构、Auction Market Theory、Volume Profile、Order Flow、Wyckoff 2.0 情景管理与案例。

图片没有逐张重新审查。现有图表保留为课程占位资产，后续可由讲师按统一视觉系统全局替换。

## 结论

原课程的 Wyckoff 基础、结构推理、风险预算、跨市场映射、研究偏差和组合治理已经达到专业课程骨架的要求。PDF 的主要增量不是重复讲解 SC、Spring、SOS、LPS、UTAD 或 SOW，而是提供了以下缺失的连接层：

1. 结构标签如何保持为可撤销假设，以及如何处理 SOT、倾斜结构、结构失败和非标准区间。
2. Auction Market Theory 如何把平衡、失衡、价格发现、时间消耗与成交分布连接起来。
3. Volume Profile 如何从指定样本中识别价值区、VPOC、HVN、LVN、VWAP 与 Profile 类型。
4. Value Area 如何转化为 Range、Reversion、Continuation 和 Failed Reversion 情景。
5. Footprint、Delta、对角失衡、吸收、主动性和 Control Test 如何只在关键交易区内辅助执行。
6. 结构、成交位置、订单流、订单选择、止损、目标和未成交机会如何合成同一套 Wyckoff 2.0 交易台流程。

因此，课程从 6 阶段、24 章扩展为 7 阶段、30 章。新增第 22—27 章，原“现代市场、研究与治理”部分顺延为第 28—30 章，以保证教学顺序为：

`结构推理 → 交易构建 → 拍卖与成交分布 → 订单流执行 → 研究与治理`

## 对 PDF 表述的专业修订

以下内容没有原样移植，因为会对职业交易员造成不必要的确定性误导：

- **VWAP**：修订为成交量加权均值；不再表述为“VWAP 上下成交量相等”。均值不等于成交量中位数。
- **Value Area**：说明 70% 或 68.2% 是平台/研究约定，不是成交量必然服从正态分布，也不是价格留在区域内的概率。
- **流动性**：不再等同于成交量，改为价差、深度、韧性、冲击与成交量的多维概念。
- **VPOC/HVN/LVN**：改为样本内成交分布描述，不直接证明买卖方控制、未来一定回访或天然支撑阻力。
- **Order Flow**：强调 Bid/Ask、Delta 和 Footprint 是主动方分类与局部数据，受场所覆盖、报价更新、隐藏流动性、聚合和平台算法影响。
- **失衡阈值**：200%、300%、400% 改为显示参数，必须按标的、时段、最小成交量和历史样本校准。
- **吸收**：需要“努力存在—价格结果受限—后续方向结果”三层证据，不能把高成交量自动解释为机构承接。
- **Naked POC/DVPOC**：要求记录回访窗口、触及容差、交易成本与对照样本，禁止直接引用跨市场固定概率。
- **Composite Operator**：保留为大规模头寸受流动性约束的分析模型，不描述为真实存在的单一操盘者。
- **订单选择**：不使用“永远不用限价单”的绝对规则，改为根据确认目标、滑点、队列风险和不成交风险选择订单。

## 讲师使用建议

新增内容面向已有多年交易经验的学生，因此没有把基础术语写成百科式说明。建议课堂采用以下节奏：

1. 先给截断图和数据口径，让学生写观察，不先展示标签。
2. 让学生提出主情景与竞争情景，并写出能改变权重的控制器。
3. 再打开 Profile，要求学生说明窗口、Session、Row Size、合约与数据源。
4. 只在预先定义的交易区展示 Footprint/Delta，讨论触发或取消。
5. 最后让学生写订单、失效、压力滑点、仓位、目标和未成交处理。

本课程把“猜中方向”排在“保留证据链、识别不确定性、及时撤销和控制损失”之后。对自营机构交易员而言，这比增加更多事件名称更接近真实的交易台工作。
